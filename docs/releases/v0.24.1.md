# PubShip 0.24.1

Client installation manifests and clearer package discovery for local PubShip use.

## Added

- Cursor plugin with declared configuration for the local service-account key path and app package names.
- Gemini CLI extension with installation settings for the same local configuration.
- `llms-install.md` for agent-assisted setup without sharing key contents, and a 400 by 400 pixel PubShip logo.

## Changed

- PyPI Homepage points to https://pubship.dev. Repository and Issues retain their GitHub destinations.
- Client manifests, the installation guide and logo stay in the Git repository; they are not bundled into the Python wheel or source archive.

## Validation

This candidate must pass the full synthetic suite, lint/format, generator checks, packaging, artifact inspection, secret scanning, manifest checks and the credential-free command before publication. No real Google API calls are part of this validation. Native Cursor and Gemini CLI installation is not implied by static manifest validation. Publication requires separate owner gates.
