# Security

Report vulnerabilities privately to **security@pubship.dev**. Do not put credentials, account data or exploit details in public issues. Include the affected version, reproduction using synthetic data, impact and relevant logs with secrets removed.

The project does not operate a Google-connected service. Operators are responsible for their own infrastructure, keys, backups and updates. Email allowlisting restricts self-host sign-in; app and capability grants independently restrict each connection. A successful synthetic test is not evidence that every live provider operation is safe.
