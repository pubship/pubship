# Final PubShip artwork

The owner supplied this final asset set on 9 October 2026. The six named originals are retained byte-for-byte here. No colors, proportions, strokes or backgrounds were redesigned.

| Asset | Use |
| --- | --- |
| `pubship-logo.svg`, `pubship-logo.png` | Black mark on white; original 1024 px PNG for the GitHub organization and directory uploads. |
| `pubship-logo-transparent.svg`, `pubship-logo-transparent.png` | Black mark on transparency for surfaces that supply their own background. |
| `favicon.png`, `favicon-16.png` | Original 32 px and 16 px browser icons. |
| `logo.svg` | Stable alias of the white-background vector. |
| `logo-mark.svg` | Stable alias of the transparent vector. |
| `logo.png` | 400 x 400 rendering of the white-background vector for the README and Cursor plugin. |

The self-host page's inline mark uses the same final transparent vector geometry. This source update does not publish a new Python package or change existing release artifacts.

## Website and public-surface synchronization

Companion [website issue #13](https://github.com/pubship/website/issues/13) replaces header/footer/diagram marks, browser and Apple icons, and the social card from the same files. Website branch `feat/final-logo` records the exact artwork mapping in `docs/branding-2026-10.md`. The footer and blue diagram retain their existing contrast treatment for the transparent mark.

Checked the website homepage's local execution, own credentials, 170-method count and 0.24.1 publication wording; setup's uvx/service-account instructions; and the permissions page's read defaults, write opt-ins and operator-owned self-hosting boundary. These claims remain unchanged. The website change is artwork and asset metadata only.

[Issue #4](https://github.com/pubship/pubship/issues/4) tracks the organization-avatar upload and directory follow-through. Third-party refreshes and the owner-controlled avatar must be verified individually. No project-run Google service, identity verification change or new Google scope is introduced.
